# Agile Planner — планировщик Agile для личного пользования

Консольный планировщик задач по методологии Agile (Kanban-доска: Backlog / In Progress / Done).

## Возможности
- добавление задачи с приоритетом;
- просмотр доски задач;
- перемещение задачи между статусами;
- сохранение состояния в файл tasks.json.

## Запуск
```
python planner.py
```

## Структура репозитория
- `planner.py` — основной модуль программы;
- `tasks.json` — файл данных (создаётся автоматически);
- `.gitignore` — служебные исключения Git.
